# FLED Box Crop

A Blender addon designed to crop and cut non-manifold meshes and open 3D surfaces (photogrammetry, LiDAR scans) without triggering the "Solver requires a manifold mesh" error.

## Installation
1. Download the `.zip` release.
2. Open Blender > Edit > Preferences > Add-ons.
3. Click **Install...** and select the downloaded file.
4. Enable the addon.
